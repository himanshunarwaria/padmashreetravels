PATTERNS

Galleries, sliders, cards, banners & the WhatsApp section

Answers to "how should these actually behave" so the extra images don't turn into extra weight or clutter.

Route / blog cards

Do: one static thumbnail per card, lazy-loaded. Don't: per-card image carousels — 13+ cards on one grid can't each carry a slider without tanking load time.

"Places to Visit" galleries

Do: CSS scroll-snap horizontal strip, native and JS-free. Don't: a JS carousel library — unnecessary dependency for 3–5 images.

Homepage hero

Do: one static photo, or none. Don't: an auto-rotating full-bleed slider — adds layout-shift risk and competes with the WhatsApp CTA for attention.

CTA banners (.cta)

Do: keep the flat black band. Don't: put a photo behind CTA text unless it's darkened enough that button contrast is untouched.

WhatsApp floating button & sticky mobile bar

Do: icon only, every page, every scroll frame. Don't: ever add an image here — it's the single most-clicked element on the site and must stay instant.

Testimonial strip

Do: a static grid or manual-swipe strip. Don't: auto-advance — hides quotes from readers who don't interact, which hurts trust on an already-thin review section.

Lightbox / full-size view

Do: a plain link-to-full-image or the native <dialog> element if you want a click-to-enlarge gallery. Don't: pull in a JS lightbox library for this.

Fleet grid

Do: 4 static cards, same lighting/background for visual consistency. Don't: mix stock car photos with real ones — inconsistency reads as untrustworthy faster than having no photos at all.

GUARDRAILS

Keeping it fast — the rules that make "more images" safe

  • Format & weight: WebP with JPEG fallback, target under 120–150KB per image — this matches the limit the site's own blog README already sets.
  • Loading strategy: loading="lazy" on everything below the fold; loading="eager" only on the single largest above-the-fold image per page.
  • Reuse relentlessly: one Taj Mahal photo set can serve a homepage route card, two route-page heroes, and three blog posts. Shoot once, deploy everywhere.
  • Cap density: one image per route card, not a gallery per card — a 13-card grid with even 3 images each is 39 requests before a visitor sees a single price.
  • Skip the long tail: Aligarh, Firozabad, Etawah, Hathras, Tundla, Sirsaganj, Shikohabad don't need dedicated shoots — one shared highway photo covers all seven.
  • Prevent layout shift: set explicit width/height or aspect-ratio on every <img> — the blog's .article-hero-img already does this correctly; extend the same pattern everywhere new images go.
FINAL PLAN

Organised shoot checklist

Four shoot days cover essentially every "Must Have" and "Recommended" row above. Days 2 and 3 need early-morning light; Day 1 can happen any time.

Day 1 — Fleet, office & drivers
Half day · controlled location · any time of day
  • 4× vehicle exteriors — Dzire, Amaze, Innova, Ertiga, same spot & light
  • 1× interior — clean seats / AC vents, reusable across all 4 cars
  • 1× boot / luggage space
  • Office exterior + signage, 2–3 angles
  • Founder / team photo
  • 3–5 driver portraits + 1 group shot, beside a cab
  • 1× ID / badge close-up
  • 1× vehicle sanitisation in progress
  • 1× driver assisting a senior passenger into the car
Day 2 — Agra monuments
Full day · highest ROI · start before sunrise
  • Taj Mahal — main gate view + sunrise glow (serves 3 route pages + 2 blog posts + homepage card)
  • Agra Fort exterior
  • Baby Taj (Itimad-ud-Daulah)
  • Akbar's Tomb, Sikandra
  • Mehtab Bagh — sunset Taj view
  • Fatehpur Sikri — Buland Darwaza
  • Cab + driver waiting shot at 1–2 monuments above
Day 3 — Mathura, Vrindavan & Barsana
Full day · second-highest ROI · evening aarti at Vishram Ghat if timed right
  • Krishna Janmabhoomi, Mathura
  • Dwarkadhish Temple, Mathura — exterior only
  • Vishram Ghat — ideally at evening aarti
  • Banke Bihari Temple, Vrindavan — exterior/gate only
  • Prem Mandir — day shot, illuminated night shot if feasible
  • ISKCON Vrindavan
  • Nidhivan
  • Radha Rani Temple, Barsana

Note: Banke Bihari and Dwarkadhish prohibit photography/phones inside the inner sanctum — plan for exteriors, gates and approach streets only.
